## Implementation Steps (per group)

Each group can be spawned as an independent agent session:

1. **Source clips** — Find/record a 12-14s vertical (9:16) demo video for each exercise
2. **Save clip files** — Place MP4s in `frontend/public/clips/bodyweight/{slug}.mp4`
3. **Update manifest** — Add entries to `frontend/public/clips/manifest.json` under a `"bodyweight"` key with appropriate workout1/workout2 sub-keys
4. **Wire up the component** — On first group only: update `frontend/src/app/bodyweight/day/[date]/client.tsx` to fetch manifest data and render `ExerciseClip` (copy pattern from `frontend/src/app/2025/day/[date]/client.tsx`)
5. **Update data** — Set `videoId: "bodyweight"` in `frontend/src/data/workouts-bodyweight.ts` for each session
6. **Test** — Verify clips render on the bodyweight day view in browser
