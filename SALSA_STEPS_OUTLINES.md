# Beginners Cuban Salsa Steps Course — per-class outlines

**Source:** La Suerte Dance School, playlist `PL8hFYIpg2Jp1XK-ADBSd0B78_KgkdckYH` (15 classes, solo footwork).
**Derived from:** local Whisper `large-v3-turbo` transcripts, term-normalised —
`data/cache/salsa/whisper/<VIDEO_ID>.norm.json` (word-level timings) — plus
`data/cache/salsa/info/<VIDEO_ID>.info.json` (`chapters`, `description`).
**Written:** 2026-09-13. Charter: `SALSA_TAB_GOALS.md`.

## How to read this

- Class order is the channel's playlist order (charter, "Decided"). Not reordered.
- Step names are verbatim from each class description or from the teachers' own
  spoken naming. Nothing here is renamed, translated or invented (**R1**).
- Every cue carries a source timestamp in seconds from video start (**R3**).
  Deep link: `youtu.be/<VIDEO_ID>?t=<seconds>`.
- Segment roles: `teach` / `count` / `music` / `review` / `skip` (charter vocabulary).
  `count` = demonstrated slowly with spoken counting, no music. `music` = full tempo
  with music. Note that in this course the `count` passages are **nested inside**
  `teach` blocks rather than being separate chapters — the couples course's clean
  "fluently with count" chapter does not exist here. Nested `count` windows are
  listed indented under their parent `teach`.
- These are all solo footwork classes, so there is no partner lead. Where the
  teachers split instruction by role ("guys…" / "girls…") the cue is tagged
  **[leader]** or **[follower]** per **R4**. Untagged cues apply to both.
- Whisper renders the teachers' rhythm vocalisations ("cheeky cheeky", "kum kuku",
  "boom boom", "ticky ticky", "chaka tiki", "poku", "nya nya") as words. **These are
  not instructions** — they are the teachers singing the beat. They are left in
  quoted passages for fidelity but must never be parsed as footwork.
